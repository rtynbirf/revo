## 3. Механика оригинала, восстановленная из поста (что именно чиним)

1. Пользователь описывает сцену → система держит **лейаут** (структуру) как главный объект.
2. Уточнение — двумя путями, ОБА обязаны быть в нашем UI (F-19/F-21):
   словами поверх лейаута (NL-инструкция) и **прямым редактированием структуры**.
3. Рендер следует за структурой; одинаковое число регионов ↑ → реконструкция точнее
   (CLIP 0.865 → 0.929 к 50 регионам) — обоснование F-26/F-27.
4. Модель оригинала принимала «любую комбинацию лейаутов, инструкций и картинок» —
   наш аналог: compose(task) + image_ref (v1.1) + image2layout (M5).

## 4. Целевые экраны REVO-APP (наша реставрация, своё имя)

### Экран 1 «Композер» (страница входа)
Поле задания + размер полотна + кнопка «Собрать лейаут» (POST /api/compose) + показ выбранного
архетипа/мозга (какого brain) + библиотека паттернов (GET /api/patterns).

### Экран 2 «Редактор лейаута» — сердце
- канвас: зоны прямоугольниками, цвета по глубине, подписи id/role, крест точки схода
  (визуальный язык — как наш skeleton, не как их брендинг);
- мышь: нарисовать новую зону (N), двигать, ресайз за уголки, Delete;
- инспектор зоны: id, role (EN), z (1/2/3 = far/mid/near), color (палитра сцены), glow;
- инспектор сцены: mood, light, perspective (клик по канвасу), palette (base/primary/accent/warm);
- кнопки: Validate, Скелет, Промпт, Рендер (offline|zai), Критик, Склейка;
- NL-поле: «инструкция словами» → compose/refine → диф зон подсвечивается.

### Экран 3 «Кадр»
Скелет | Рендер | Склейка; таблица критика по зонам (score, mean_rgb, детальность, вердикты);
кнопка «Ещё попытка» (рефайн), история попыток.

### Экран 4 «Проекты» (M4)
Список проектов, история версий с дифами, экспорт/импорт zip.

**Hotkeys:** N — новая зона · Del — удалить · 1/2/3 — far/mid/near · Ctrl+E — экспорт layout.json · Ctrl+Enter — прогон цикла.

**Приёмка M3 (чеклист агента-UI):** каждое действие экрана 2 выполняется в браузере;
layout.json из UI проходит `revo.py validate`; приёмка цикла экрана 3 даёт pass/score;
скриншоты в `demo/ui/` одним коммитом.
