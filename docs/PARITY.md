**Что это.** Каждому пункту чеклиста RESTORE-APP §5 присвоен ровно один вердикт:
✅ восстановлено / 🔶 восстанавливается (фаза, задача) / ⛔ честно не восстанавливаем.
Ни одного пункта без вердикта — это и есть приёмка F-24.

**Метод.** Каждый вердикт опирается на файлы/команды этого репо и источники RESTORE-APP §2–3,
не на память: команды ядра перегнаны при подготовке этого документа (selftest 12/12,
validate/compose/skeleton/prompt/render/merge — зелёные, см. блок 1), факты об оригинале взяты
только из [SPEC.md](../SPEC.md) §1–2 и RESTORE-APP §1–3 (Wayback-снапшоты 05.11 и 28.10.2026,
архив 41 файл с пломбой SHA256, блог-пост «The Layout Bet»).

**Связь с SPEC §3.** Формула «100%»: *каждый пункт P0 из SPEC §5 в статусе ГОТОВО +
docs/PARITY.md закрыт или честно помечен + selftest/приёмка зелёные*. Этот документ закрывает
второе слагаемое. «100%» = функциональный паритет метода на открытых рельсах, не «100% пикселей
Reve» и не веса модели (SPEC §3, §9). Правило N-10: **честный красный лучше зелёной лжи** —
потому ниже пять 🔶, а не восемь ✅.

## Блок 3 · «Честно не восстанавливаем» (пункты 10–12): причины

**№10 — веса Large Layout Model.** Публично не существуют: охота по 10 каналам (GitHub org `reve-art` — 0 репозиториев; HF, GitLab, Sourcegraph — пусто; журнал `context/source_code_hunt.md`) зафиксирована в SPEC §1; архив снятия (41 файл) запломбирован SHA256 `c606ce5b…a3ac99` в приватном `polimat-hub/vault/`. Референсный код команда Reve раздаёт только письмом на `training-infra@reve.art`. Следствие: ни один реставратор в мире не может вернуть веса — это потолок возможного (SPEC §3: «Это максимум, доступный человечеству: остального не существует»). Наш ответ — подключаемые рендер-бэкенды (F-25, M5) и offline-first ядро. Это ⛔ навсегда, не «пока».

**№11 — iOS-приложение / Chrome-расширение.** Обе поверхности известны только упоминанием в портфолио дизайнера Reve (RESTORE-APP §1); механик, экранов, взаимодействий в проверенных источниках нет. Правило реставратора №1 (RESTORE-APP §6): не придумывать UI-механики, которых не видели. Статус: P2, вне репо-плана до M6 (ROADMAP M6 — «P2 на потом, честно»). Это ⛔ для первой очереди с честной пометкой, а не 🔶: дорожная карта ничего не обещает.

**№12 — аккаунты / облако / платежи.** Облако оригинала выключено (генерация 27.09.2026, вход 31.10.2026 — SPEC §1, два независимых источника) и не нужно по нашей архитектуре: REVO — локальный продукт, один stdlib-процесс сервера (F-14, M2), файловые проекты (F-22, M4), CI-клетка вместо фермы (F-13). Offline-first — нефункциональное требование N-01. Плюс юр-гигиена (SPEC §8): ноль ассетов/текстов/имён Reve, своё имя REVO, MIT.
