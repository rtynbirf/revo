# AGENTS.md — правила роя для этого репо

- **Что это**: REVO — дом прототипа метода Reve (layout → render). Ядро — `revo.py`, сцены — `layouts/*.json`.
- **Миссия с 2026-11-09**: восстановление закрытого app.reve.com как открытой системы. Перед работой читай `SPEC.md` (ТЗ) и `ROADMAP.md` (фазы M0..M6); контракты — `docs/FORMAT.md`, `docs/API.md`, карта оригинала — `docs/RESTORE-APP.md`, вердикты парити — `docs/PARITY.md`.
- **Числа никогда руками**: размеры, счётчики, статусы — только из живого API/кода, не по памяти.
- **Проверяй строкой**: изменение считается свершившимся только после raw 200 / зелёного прогона.
- **Ничего не удалять без пломбы**: саркофаг (bundle + SHA256) — в `polimat-hub/vault/`.
- **Связь пинами**: соседние миры — `polymath-gen` (полный агент), `rtynbirf/rtynbirf` (cells), `polimat-hub` (сверки роя).
- **Демо = доказательство**: после изменения пайплайна перегони `layouts/*.json` и обнови `demo/` одним коммитом.
- **Честный красный лучше зелёной лжи**: сломалось — фиксируй в README/честном статусе, не прячь.
